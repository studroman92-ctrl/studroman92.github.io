# Свадебное приглашение для GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него содержимое этой папки: `index.html`, `style.css`, `og.png` и этот файл.
3. Откройте **Settings → Pages** и в разделе Source выберите **Deploy from a branch**, затем ветку `main` и папку `/(root)`.
4. После публикации в **Settings → Pages** укажите свой домен в поле **Custom domain**.

Для поддомена, например `www.example.ru`, добавьте в DNS запись `CNAME`, которая указывает на `ваш-логин.github.io`.

Форма ответа в этой статической версии показывает благодарность, но не отправляет данные. Для настоящего сбора ответов подключите Google Forms или Formspree.
